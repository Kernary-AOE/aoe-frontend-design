# AiGeneratedUi [anti-pattern] v1.0.0
The predictable visual fingerprint shared by all unconstrained AI-generated UIs: Inter font + purple-to-blue gradient + rounded-2xl everywhere + shadow-lg on every card + hero→3col→testimonials→CTA layout — immediately recognizable as machine-generated because it represents the statistical mode of Tailwind/shadcn training data.
domain: frontend-design

## Label
AI-Generated UI Convergence

## Trap
AI models optimize toward training-data averages. The statistical median of the internet is a SaaS marketing page built with Tailwind CSS defaults. Without a persona brief and explicit constraints, every model — v0, Bolt, Claude, ChatGPT — converges on this same output. A/B v4 data showed 3 unguided Sonnet agents independently chose #6d4aff / #6c3bff / #6c63ff — all within 15° of purple.

## Detection Heuristics
- Primary font is Inter, Plus Jakarta Sans, DM Sans, or Roboto
- Color palette uses purple-to-blue gradient (#7C3AED → #3B82F6) or Tailwind violet-500/indigo-600
- rounded-2xl applied to buttons, cards, images, and inputs indiscriminately
- shadow-lg is the only shadow — every elevated element looks identical
- Page structure is exactly: hero → 3-column features → testimonials → CTA
- Zero scroll-triggered animation or only fadeIn
- All icons from Heroicons or Lucide without any customization
- All cards visually identical — same padding, radius, shadow, layout
- Gap-4 or gap-8 used for all spacing throughout

## Scoring
0 signals = distinctive. 1-3 = targeted fixes needed. 4-6 = generic AI output. 7+ = slop — restart with persona selection.
