# CtaSectionGallery [example] v1.0.0
17 curated CTA section screenshots from Land-book Pro, tagged by pattern type and persona lean. CTA sections are inflection points in the scroll narrative — they ask the visitor to make a decision. They appear in two primary positions: mid-page (as momentum checkpoints) and end-of-page (as the final conversion moment).
domain: frontend-design

## Observations
- B2B products almost always offer a 'book a demo' or 'talk to sales' path, not a self-serve signup. GTM Analytics, Pontera, V7-Go, Happyrobot, and Rhetorich all funnel to a consultation or demo rather than a free trial. The CTA copy is qualified ('for enterprises,' 'for finance teams') which intentionally filters out low-intent visitors. Self-serve signups (base44, bright-os in the wider gallery) use low-friction copy like 'get started free.'
- Developer-facing CTAs treat code as the conversion action. Codegen and Inertiajs frame their CTAs around code actions: an install command, a GitHub star, a documentation link. The button is present but secondary to the code metaphor. This signals comfort with the developer audience — they trust the visitor to execute independently.
- Dual-path CTAs appear when a product serves two distinct audiences. Cardless (developer vs. business), Modern Vendor Financing (apply vs. partner), and Veo (shop vs. trial) all use two equally weighted actions. This is preferable to forcing one audience's path on another. The visual treatment is typically two side-by-side buttons: one primary (filled), one secondary (outlined or ghost).
- Trust signals adjacent to the CTA reduce conversion anxiety. GTM Analytics, Pontera, and Modern Vendor Financing all place company logos, compliance badges, or social proof immediately below or above the CTA button. This pattern is especially common in fintech and enterprise — the implicit message is 'other credible organizations already made this decision.'
- Emotional and wellness products use soft persuasion, never urgency. Dawn AI's CTA uses reassurance-oriented copy; no countdown timers, no 'limited time' framing. This is consistent with the warm-institutional and editorial personas — urgency tactics would damage brand trust in sensitive categories (mental health, wellness, healthcare).

## Agent Workflow
```
    1. Determine CTA position first: mid-page checkpoint or final end-page conversion. Mid-page CTAs (cernel, keytail) are lower-friction and shorter. End-page CTAs (aira, interfere, client-challenge) carry the full conversion weight of the page.
    2. Match copy mode to product category. Enterprise/B2B: outcome framing + demo path. Developer: code action + secondary button. Consumer/wellness: reassurance copy + single clear action. Hardware: photography + dual path.
    3. Use trust signal samples when the product is high-stakes. GTM Analytics and Modern Vendor Financing demonstrate how to surround a CTA with credibility signals without making the section visually noisy. 4-6 muted logos below the button is the standard execution.
    4. Cross-reference pricing for dual-path logic. The dual-path CTA pattern often mirrors pricing tier logic — understanding how the product segments buyers in the pricing gallery helps write the right two CTA labels.
    5. End-page CTAs should echo hero language. Aira's end-page CTA mirrors its hero headline. This creates a narrative loop. When selecting a CTA sample, check if the hero sample (from the hero gallery) uses compatible language patterns.
  
```
