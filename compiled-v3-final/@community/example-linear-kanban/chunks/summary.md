# LinearKanban [example] v1.0.0
Linear's board view shows columns (Backlog / Todo / In Progress / Done) with subtle column headers and stacked cards. Each card is ~280px wide with 12px padding, showing issue ID, title, assignee avatar (16px), and labels as colored dots. Drag-and-drop uses a faint scale(1.02) lift and a placeholder rectangle at the drop target.
domain: visual-design
