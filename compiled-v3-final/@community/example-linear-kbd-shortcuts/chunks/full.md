# LinearKbdShortcuts [example] v1.0.0
Linear's issue tracker exposes nearly every action through a command palette (Cmd/Ctrl+K) and single-key shortcuts (e.g. 'C' to create issue, 'P' to set priority). The shortcut system is discoverable via a persistent tooltip on every interactive element showing the key binding. The result is an interface where power users operate almost entirely without mouse interaction.
domain: frontend-design

## Label
Linear — Keyboard-First Command Interface

## Url
https://linear.app

## Observed
2024-Q4

## Demonstrates
- Single-character shortcuts accelerate expert workflows dramatically (< 1 keystroke per action vs 3+ mouse interactions).
- Command palette with fuzzy search as universal escape hatch — users never need to remember exact shortcuts.
- Shortcuts are shown inline in context menus and tooltips, supporting learning-by-doing rather than requiring documentation.
- Action grouping in the palette (Issues, Projects, Views) reduces cognitive load of a large command surface.

## Quality Signals
- no-mouse workflows complete in measurably fewer interactions
- new users discover shortcuts organically through tooltip exposure
- accessibility: all palette items are announced by screen readers; focus is trapped correctly while palette is open
