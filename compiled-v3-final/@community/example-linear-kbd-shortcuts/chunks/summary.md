# LinearKbdShortcuts [example] v1.0.0
Linear's issue tracker exposes nearly every action through a command palette (Cmd/Ctrl+K) and single-key shortcuts (e.g. 'C' to create issue, 'P' to set priority). The shortcut system is discoverable via a persistent tooltip on every interactive element showing the key binding. The result is an interface where power users operate almost entirely without mouse interaction.
