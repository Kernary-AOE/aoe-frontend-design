# ConsistencyStandards [fact] v1.0.0
> Nielsen Heuristic 4 — Consistency and Standards: Users should not have to wonder whether different words, situations, or actions mean the same thing. Follow platform and industry conventions.
domain: ux-design

## Confidence
proven

## Evidence
@nielsen/source-nielsen-1994

## Heuristic Number
4

## Violations
- Delete action is red in one part of the UI, grey in another.
- Some modals close with Escape, others require clicking X explicitly.
- Navigation items change label or position between different sections of the app.

## Examples
- Using the same icon for 'Settings' (gear) throughout the entire product.
- Primary action button always the same color (brand blue) in every dialog.
- Keyboard shortcuts matching the OS convention: Cmd+S to save on macOS.
