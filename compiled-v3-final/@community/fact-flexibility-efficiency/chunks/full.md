# FlexibilityEfficiency [fact] v1.0.0
> Nielsen Heuristic 7 — Flexibility and Efficiency of Use: Accelerators — unseen by the novice user — may often speed up the interaction for the expert user such that the system can cater to both inexperienced and experienced users. Allow users to tailor frequent actions.
domain: ux-design

## Confidence
proven

## Evidence
@nielsen/source-nielsen-1994

## Heuristic Number
7

## Violations
- All common actions require 3+ click navigations with no shortcut alternative.
- Frequently-used actions buried in dropdown menus with no keyboard access.
- No way to batch-select and operate on multiple items simultaneously.

## Examples
- Keyboard shortcuts for every menu action (invisible to mouse-only users; powerful for experts).
- Command palette (@community/pattern-command-palette) as an accelerator layer over GUI menus.
- Customizable dashboard layouts saved per user.
- Browser address bar that accepts both URLs and search queries.
