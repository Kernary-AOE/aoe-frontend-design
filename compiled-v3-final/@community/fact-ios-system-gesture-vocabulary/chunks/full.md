# IosSystemGestureVocabulary [fact] v1.0.0
iOS defines a standard set of touch gestures with established, consistent meanings across all apps: tap (select/activate), long press (context menu/preview), horizontal swipe (delete/archive/back), vertical swipe (scroll/dismiss), pinch (zoom), and two-finger rotate (rotate content).
domain: frontend-design

## Evidence
- tap: primary action or selection — tapping a cell selects it, tapping a button triggers it.
- long press: reveals context menu (.contextMenu) or enters edit mode; in Photos/Safari it previews content.
- swipe horizontal (trailing edge): swipe-to-delete or swipe-to-archive on list rows.
- swipe horizontal (leading edge from left): system back navigation in navigation stacks.
- swipe vertical (sheet): dismisses a presented sheet modal.
- pinch: zoom in/out on maps, photos, and web content.
- two-finger rotate: rotates manipulable objects (Maps, image editors).
