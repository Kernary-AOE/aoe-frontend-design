# MatchRealWorld [fact] v1.0.0
> Nielsen Heuristic 2 — Match Between System and the Real World: The system should speak the users' language, with words, phrases, and concepts familiar to the user, rather than system-oriented terms. Follow real-world conventions, making information appear in a natural and logical order.
domain: ux-design

## Confidence
proven

## Violations
- Error messages showing raw stack traces or HTTP status codes to end users.
- Form field labeled 'SKU' when the user calls it 'Product Code'.
- Technical jargon: 'null pointer', 'CORS error', '404' without translation.
