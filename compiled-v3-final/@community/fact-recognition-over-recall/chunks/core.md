# RecognitionOverRecall [fact] v1.0.0
> Nielsen Heuristic 6 — Recognition Rather Than Recall: Minimize the user's memory load by making objects, actions, and options visible. The user should not have to remember information from one part of the interface to another.
domain: ux-design

## Confidence
proven

## Evidence
@nielsen/source-nielsen-1994

## Heuristic Number
6

## Violations
- Modal dialogs that require users to remember values from a previous screen to fill in a form.
- Icon-only toolbars with no tooltips — users must memorize what each icon does.
- Autocomplete that only appears after typing 3+ characters — user must already know the exact term.
- Pagination without page number display — user must mentally track which page they are on.
