# DesignMdExtraction [method] v1.0.0
A protocol for extracting a structured design.md file from any existing UI, reference gallery screenshot, or design brief — producing a reusable design system document that can guide AI-agent frontend generation.
domain: frontend-design

## Label
Design.md Extraction Protocol

## Output
A .md file with YAML front matter and 6 sections covering color, type, spacing, components, motion, and at least one distinctive design decision.
