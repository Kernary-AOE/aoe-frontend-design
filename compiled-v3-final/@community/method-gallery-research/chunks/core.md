# GalleryResearch [method] v1.0.0
A 6-step protocol for extracting reusable design patterns from gallery sites (land-book.com, godly.website, mobbin.com) — replacing passive browsing with structured pattern extraction that produces actionable tokens.
domain: frontend-design

## Label
Gallery Research Methodology

## Anti Patterns
- Opening 15+ tabs and closing them all — inspiration without extraction is procrastination
- Saving to a design folder you never reopen — extraction happens now, not later
- Copying a layout — patterns transfer, compositions don't; always rebuild from extracted tokens
- Relying on memory — write the pattern name before closing the tab
