# BorderRadiusByPersona [pattern] v1.0.0
domain: frontend-design

## Label
Border Radius Persona Mapping

## Problem
Without a mapping from persona/product type to radius values, designers default to the middle (8–12px) or the Tailwind default (rounded-2xl = 16px), failing to communicate the product's actual personality signal through corner geometry.

## Solution
Select border-radius based on the four personality tiers mapped to product archetypes. Each tier communicates a distinct signal that must match the product's true intent.
