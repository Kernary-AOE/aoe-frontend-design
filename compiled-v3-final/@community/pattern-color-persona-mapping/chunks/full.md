# ColorPersonaMapping [pattern] v1.0.0
domain: frontend-design

## Label
Persona Color Preference Quick Reference

## Problem
Agents and designers default to safe palette choices (blue-cyan, indigo) that match no specific persona. Without a mapping from persona intent to color parameters, the palette cannot serve the product's actual audience.

## Solution
Match brand hue range, chroma level, and gray tint to the target persona using the six-persona reference table from Prime's A/B data. These are starting points to break default palettes, not mandates.
