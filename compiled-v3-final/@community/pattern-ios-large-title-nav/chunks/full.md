# IosLargeTitleNav [pattern] v1.0.0
Top-level views use large navigation bar titles that collapse smoothly to inline (standard) size as the user scrolls down. This matches the standard iOS navigation visual language users expect across system and third-party apps.
domain: frontend-design

## Label
iOS Large Title Navigation Bar

## Problem
Inline-only navigation bar titles on root views feel flat and hierarchy-less. Without a large title, primary views look identical to secondary push views, weakening the sense of navigational depth.

## Solution
Use large navigation bar title display mode on top-level (root/primary list/grid) views. Allow the title to collapse to inline on scroll. Subordinate push views use the standard inline title to reinforce hierarchy.
