# KbdShortcutChip [pattern] v1.0.0
Render keyboard shortcuts as an array of individual <kbd> elements (one chip per key, split on spaces) rather than a single <kbd> blob — the space-delimited shortcut string convention from cmdk's Raycast demo enables per-key chip visuals, clean copy-paste, and single-point platform swapping (⌘ → Ctrl).
domain: frontend-design
