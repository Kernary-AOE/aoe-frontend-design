# Stripe [persona] v1.0.0
Premium fintech marketing aesthetic: weight-300 sohne-var headlines on pure white with deep navy #061b31 headings, saturated purple #533afd CTAs, and blue-tinted multi-layer shadows that signal financial-grade confidence.
domain: visual-design

## School
stripe

## Implies
- **Font**:
  - **Display**: sohne-var (Söhne variable) with fallback SF Pro Display
  - **Body**: sohne-var weight 300 — same family, never switches
  - **Monospace**: SourceCodePro with fallback SFMono-Regular
- **Color**:
  - **Temperature**: cool-neutral
  - **Palette**: purple #533afd brand CTA, purple hover #4434d4, deep navy #061b31 headings, brand dark #1c1e54 immersive sections, body text #64748d, border #e5edf5, accent ruby #ea2261 and magenta #f96bee decoration-only
  - **Background**: #ffffff
- **Density**: compact — 4–8px radius only, 8px base spacing with dense small-end scale (1/2/4/6/8/10/11/12px), 1080px max-width
- **Layout**: white canvas with alternating #1c1e54 dark immersive sections, centered 1080px, conservative grid
- **Imagery**: abstract gradient decoration (ruby #ea2261 → magenta #f96bee) in hero only — never applied to functional UI elements
- **Motion**: restrained — blue-tinted multi-layer shadows do the heavy lifting; interactive states via opacity and color shift on sohne-var weights
