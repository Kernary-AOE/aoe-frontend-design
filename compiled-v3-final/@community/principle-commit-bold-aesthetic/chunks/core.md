# CommitBoldAesthetic [principle] v1.0.0
> Choose and fully commit to a specific, extreme aesthetic direction before writing any implementation code. Partial commitment produces incoherent outputs; bold maximalism and refined minimalism both succeed, but the hedged middle-ground does not.
domain: frontend-design

## Implications
- Select a persona (@impeccable/persona-editorial, @impeccable/persona-brutalist, etc.) before opening a code file.
- If the brief is ambiguous, prototype two extreme directions rather than one safe middle — let contrast testing decide.
- A wrong commitment is easier to fix than an uncommitted output — you can pivot from a coherent direction.
- Commit to an aesthetic in writing (design.md or a comment block) before touching CSS.
