# UiDifferentiationMemorability [principle] v1.0.0
> Before building any UI, identify the one element a user will remember — and execute it with precision. Undifferentiated UIs have no recall value.
domain: frontend-design

## Attributed To
Anthropic Frontend Design Skill

## Applies To
- frontend-design
- design thinking before implementation
- any UI that will compete for user attention

## Examples
- Linear: the narrow, precise monospace-influenced data density is the unforgettable differentiator in a world of padded cards.
- Notion: the slash command menu that turns the editor into a creation tool — no other app had it first.
- Figma: the real-time multiplayer cursor stack — makes the collaboration visible in a way that felt impossible.
- Bad: 'a clean, modern interface with rounded corners and a blue primary button' — describes 10,000 SaaS apps simultaneously.

## Rationale
Gravitating toward safe, common choices produces UIs that blend into the statistical mean of AI-generated output. A single strong differentiator — a distinctive typography treatment, a non-standard compositional move, a reserved signature color, an unexpected interaction — anchors user memory and brand identity.
