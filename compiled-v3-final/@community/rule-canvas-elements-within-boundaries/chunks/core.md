# CanvasElementsWithinBoundaries [rule] v1.0.0
> Every text, graphic, and visual element in a canvas art output (.pdf or .png) must remain within canvas boundaries with proper margins. No elements may be clipped by the canvas edge. No two elements may overlap. All elements must have visible breathing room from adjacent elements.
domain: frontend-design

## Severity
block

## Applies When
Generating any static canvas art, poster, or print-format design artifact.

## Verify By
Nothing falls off the canvas edge. No two elements overlap. All elements have clear separation from adjacent elements.
