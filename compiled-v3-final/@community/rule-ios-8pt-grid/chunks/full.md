# Ios8ptGrid [rule] v1.0.0
> All spacing and sizing values in iOS layouts must align to multiples of 8pt; use 4pt only for fine adjustments.
domain: frontend-design

## Applies To
all spacing, padding, margin, gap, and element dimension values in iOS apps

## Examples
- Card padding: 16pt (2 × 8pt) top/bottom, 16pt left/right.
- List row height: 48pt (6 × 8pt).
- Icon-to-label gap: 8pt; section-to-section gap: 24pt.

## Rationale
The 8pt grid creates consistent visual rhythm and aligns to iOS's design density expectations. Values of 4, 8, 16, 24, 32, 40, and 48pt map cleanly onto the logical pixel grid across all Retina densities.
