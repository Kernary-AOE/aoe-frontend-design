# VaryAestheticPerGeneration [rule] v1.0.0
> Each generated UI must vary its theme, fonts, and aesthetic — never reuse the same choices generation after generation. NEVER converge on common choices (e.g. always Space Grotesk) across distinct UI generation requests.
domain: frontend-design

## Severity
warning

## Use Instead
Vary between light and dark themes, select different font pairings, and use distinct aesthetic modes per request context. Consult the persona library to pick a different starting point each time.

## Sources

## Rationale
Gravitating toward the same font, color scheme, or layout style across multiple distinct UI generation requests collapses diversity and marks output as uncreatively AI-generated. Familiar choices feel safe and require no aesthetic reasoning — exactly the trap that produces slop.
