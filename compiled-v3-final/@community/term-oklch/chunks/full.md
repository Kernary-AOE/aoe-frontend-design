# Oklch [term] v1.0.0
> A perceptually-uniform polar color space (Lightness, Chroma, Hue) built on the Oklab color model, standardized in CSS Color Level 4. Each channel has an intuitive meaning: L (0–1) is perceived lightness; C (≈ 0–0.4) is perceived chroma/saturation; H (0–360°) is hue angle.
domain: visual-design

## Meaning
A perceptually-uniform polar color space (Lightness, Chroma, Hue) built on the Oklab color model, standardized in CSS Color Level 4. Each channel has an intuitive meaning: L (0–1) is perceived lightness; C (≈ 0–0.4) is perceived chroma/saturation; H (0–360°) is hue angle.
