# Rasterization [term] v1.0.0
> The process by which vector graphics, font glyphs, and CSS-defined shapes are converted into a pixel grid for display. Rasterization happens inside the GPU/CPU rendering pipeline of the browser and determines whether edges appear sharp, soft, or aliased on the user's screen.
domain: visual-design

## Meaning
The process by which vector graphics, font glyphs, and CSS-defined shapes are converted into a pixel grid for display. Rasterization happens inside the GPU/CPU rendering pipeline of the browser and determines whether edges appear sharp, soft, or aliased on the user's screen.

## Aliases
- rastering
- scan conversion
- rendering to pixels
