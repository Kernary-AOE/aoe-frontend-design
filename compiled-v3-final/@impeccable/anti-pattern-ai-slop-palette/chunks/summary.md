# AiSlopPalette [anti-pattern] v1.0.0
The statistically predictable default visual language produced by AI code generation tools when given no specific brand constraints: Inter typeface + saturated purple (#7c3aed–#8b5cf6) + near-black background + rounded corners everywhere + glowing shadow effects. Recognizable at a glance as machine-generated, communicates no brand identity, and satisfies only the lowest bar of 'looks professional'.
