# NielsenTenHeuristics [taxonomy] v1.0.0
Jakob Nielsen's ten general principles for interaction design, derived from factor analysis of 249 usability problems. Used as the evaluation framework in heuristic review sessions. Each member fact represents one heuristic.
domain: ux-design

## Evaluation Scale
- **0**: Not a usability problem at all
- **1**: Cosmetic problem only — fix only if spare time
- **2**: Minor usability problem — low priority fix
- **3**: Major usability problem — important to fix
- **4**: Usability catastrophe — fix before release
