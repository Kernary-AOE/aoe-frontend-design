# WcagFocusContrast [fact] v1.0.0
> WCAG 2.2 SC 2.4.11 (Level AA) requires that the focus indicator for a keyboard-focused UI component has a contrast ratio of ≥ 3:1 between the focused and unfocused states, and the focus indicator area must be at least as large as a 2 CSS pixel perimeter around the component.
domain: accessibility
