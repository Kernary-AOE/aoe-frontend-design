# Wcag22 [source] v1.0.0
The W3C normative standard for web content accessibility. WCAG 2.2 was published as a W3C Recommendation on 5 October 2023. It extends WCAG 2.1 with nine new success criteria, notably SC 2.4.11 (Focus Not Obscured Minimum), SC 2.4.12 (Focus Not Obscured Enhanced), SC 2.5.7 (Dragging Movements), SC 2.5.8 (Target Size Minimum), and SC 3.3.7 (Redundant Entry).
domain: accessibility
